Encuadre y Jerarquía Visual

Percepción visual humana (C. Ware)
  • Encuadre (framing): definir el espacio visual donde se presenta la información, evitando elementos distractores y enfocando la atención en lo relevante.

Ejemplo del texto

En un gráfico de barras, la barra con el dato más relevante puede resaltarse con un color más intenso para atraer la atención — el resto queda en un tono neutro que no compite por la mirada.

De un Gráfico Manipulado a uno Honesto (Plotly)

px.pie con personalización
import plotly.express as px import pandas as pd data = {'Compañía': ['Apple', 'Google', 'Microsoft', 'Otras'], 'Cuota de Mercado (%)': [35, 15, 10, 40]} df = pd.DataFrame(data) fig = px.pie(df, values='Cuota de Mercado (%)', names='Compañía', hole=0.4, color_discrete_sequence=px.colors.qualitative.Pastel) fig.update_traces(textinfo='percent+label', pull=[0.05, 0, 0, 0]) fig.show()
  • Los datos de ambos gráficos (el manipulado y el corregido) son simulados, pensados para mostrar el contraste.
  • hole, pull y color_discrete_sequence mejoran la estética sin alterar el dato — la manipulación está en la escala/ejes, no en el estilo.

Resampling Semanal y Media Móvil (Rolling)

Dos transformaciones clave
  • Resampling semanal: agrupar los valores diarios en semanas (que arrancan el lunes) y calcular la media de cada semana.
  • Rolling de 3 semanas: media móvil sobre la serie ya resampleada, usando window=3 y min_periods=3 (solo se muestra cuando la ventana está completa).

Por qué importa

El resampling reduce ruido diario y el rolling suaviza aún más la tendencia — ambas son técnicas base para leer series temporales de negocio o financieras sin perderse en la variación día a día.

¿Qué Significa que un Notebook sea Reproducible?

Siempre el mismo resultado

Hoy, mañana, en otra computadora o en Colab: los valores deben coincidir. Se logra fijando semillas y sin depender del orden de ejecución manual.

Ejecuta de arriba a abajo

Debe funcionar con Runtime → Run all: nada de celdas ejecutadas "a mano" ni variables sueltas fuera del flujo.

No depende del usuario

Sin input(), sin leer de stdin: los datos de ejemplo se construyen directamente en el código.

Escribir código que funcione no es suficiente — un análisis profesional debe ser reproducible por cualquier persona, desde cero.

Semillas Aleatorias y Funciones Puras

np.random.seed(42) random.seed(42) # Problema base: sumar múltiplos # de 3 o de 5 en una colección
¿Por qué una semilla fija?
  • np.random, random y la generación de fechas/precios producen resultados distintos en cada corrida si no se controlan.
  • Una función pura recibe datos y produce un resultado, sin modificar variables externas ni depender del entorno.

La función recorre la colección una sola vez (eficiencia), convierte a enteros, verifica la condición y acumula — escalable incluso a 100.000 elementos.

Pairplots y Scatter Matrix

Todas las combinaciones de a pares
  • Pairplot: matriz de gráficos con un scatter plot por cada par de variables numéricas, y un histograma o densidad en la diagonal.
  • Scatter Matrix: equivalente, para observar correlaciones y distribuciones conjuntas visualmente.

Ejemplo en la industria

En análisis financiero, un pairplot puede mostrar cómo se relacionan indicadores económicos como PIB, inflación y tasa de interés, para detectar patrones o anomalías.

Técnicas para Reducir la Complejidad Visual

  • Selección de variables clave: elegir solo las más relevantes para el análisis.
  • Agrupación o segmentación: dividir el dataset en subgrupos para análisis más focalizados.
  • Paletas y estilos consistentes: facilitan la distinción visual sin sobrecargar.
  • Interactividad (vista previa): preparar visualizaciones interactivas ayuda a explorar dimensiones sin saturar la vista — lo vemos en el módulo de Plotly.

Ejemplo real: un científico de datos en salud pública puede usar un pairplot para explorar cómo edad, presión arterial, colesterol y actividad física se relacionan entre sí y con la incidencia de enfermedades.

Tres Familias de Paletas de Color

Cualitativas

Para variables categóricas sin orden inherente. Ej: tipos de frutas, regiones, categorías de producto.

Secuenciales

Para variables numéricas ordenadas, donde el color indica magnitud. Ej: temperatura, densidad de población.

Divergentes

Para variables con un punto medio crítico, mostrando desviaciones en dos direcciones. Ej: diferencias respecto a un valor base.

Seaborn facilita la selección con color_palette() y cubehelix_palette(), con opciones accesibles y profesionales ya definidas.

Accesibilidad Cromática: Daltonismo y Escala de Grises

~8% de hombres, ~0.5% de mujeres

Conceptos Clave de Matplotlib

Figure y Axes

Figura: el contenedor principal. Ejes (axes): el área donde efectivamente se dibuja el gráfico.

plot y scatter

plot traza líneas; scatter traza puntos de dispersión. Ambos aceptan color, etiqueta y estilo.

Guardar y componer

Matplotlib es la biblioteca base de la visualización en Python: desde una línea simple hasta composiciones complejas con múltiples paneles.

Ejemplo Básico: Figura, Línea, Dispersión y Leyenda

fig, ax = plt.subplots() x = [1, 2, 3, 4, 5] y = [2, 3, 5, 7, 11] ax.plot(x, y, label='Serie 1', color='blue') ax.scatter(x, y, color='red', label='Puntos') ax.set_xlabel('Eje X'); ax.set_ylabel('Eje Y') ax.set_title('Ejemplo básico de Matplotlib') ax.legend() fig.savefig('grafico.png', dpi=300, format='png') plt.show()

Un mismo eje (ax) puede combinar plot y scatter — cada llamada agrega una capa nueva sobre el mismo gráfico.

Subplots: Comparar Varias Vistas a la Vez

fig, axs = plt.subplots(1, 2, figsize=(18, 8)) axs[0].plot(x, y, color='blue') axs[0].set_title('Gráfico de línea') axs[1].scatter(x, y, color='green') axs[1].set_title('Gráfico de dispersión') plt.tight_layout() plt.show()
Una grilla de ejes
  • plt.subplots(1, 2, ...) devuelve un arreglo de ejes (axs[0], axs[1]), cada uno independiente.
  • tight_layout() ajusta los espacios para que no se superpongan etiquetas.

Cuartiles, IQR y Detección de Outliers

IQR = Q3 - Q1 lower = Q1 - 1.5 * IQR upper = Q3 + 1.5 * IQR # fuera de [lower, upper] -> outlier
La regla del boxplot
  • Q1 (25%) y Q3 (75%) delimitan el rango intercuartílico.
  • Cualquier valor fuera de [Q1 - 1.5·IQR, Q3 + 1.5·IQR] se considera outlier.

Dataset de práctica: ventas de e-commerce (OrderAmount), combinando Gamma (compras normales), log-normal (compras grandes, "heavy tail") y uniforme (promociones puntuales).

Multimodalidad y Skewness (Asimetría)

Multimodalidad
  • Se suaviza el histograma con una media móvil y se cuentan los picos locales (valores mayores que sus vecinos).
  • Más de un pico → conviene un KDE, que muestra la forma continua y suavizada.
# skewness: tercer momento # central normalizado skew = mean((x - x̄)³) / σ³

Si la distribución es muy sesgada (skewness alto), un histograma puede ocultar información — ahí el violinplot muestra forma y dispersión de manera más completa.

¿Por Qué GridSpec y no plt.subplot()?

Grillas rígidas vs. flexibles
  • plt.subplot(2, 2, 1) limita a una grilla pareja y rígida.
  • GridSpec permite que un subplot ocupe varias filas o columnas — paneles principales y secundarios, como en un dashboard real.

Validar el Layout antes de Dibujar

Un layout inválido no debe construirse
  • Tipos correctos (enteros), r, c ≥ 0, h, w > 0.
  • Límites del grid: r + h ≤ R y c + w ≤ C.
grid = np.zeros((R, C)) # marcar celdas ocupadas; # si ya estaba ocupada -> ERROR

Detectar solapamientos es equivalente a una detección de colisiones espaciales — clara, determinística y fácil de depurar.

Coverage y Construcción Final del Dashboard

coverage = celdas_ocupadas / celdas_totales gs = GridSpec(R, C) ax = fig.add_subplot( gs[r:r+h, c:c+w])

  • Cada subplot final puede contener barras, series temporales, boxplots o heatmaps.

PNG, SVG o PDF: ¿Cuál Elegir?

FormatoCuándo usarlo
PNGRasterizado, ideal para pantalla. Soporta transparencia; calidad depende del DPI.
SVGVectorial, escalable sin pérdida — ideal si el gráfico se va a redimensionar o editar después.

La elección depende del uso final: pantalla (PNG), edición o escalabilidad (SVG), impresión o documentos formales (PDF).

DPI, Tipografías y Ajustes para Diapositivas

plt.savefig('grafico.png', dpi=300) plt.rcParams['font.family'] = 'Arial' plt.rcParams['font.size'] = 12
Reglas prácticas
  • Pantalla: 72-100 DPI suele alcanzar.
  • Impresión: 300 DPI o más, para evitar pixelación.
  • Ajustar figsize para que encaje en la diapositiva o página, sin cortar etiquetas.

Antes de exportar, conviene visualizar el gráfico en su tamaño final para detectar problemas de legibilidad.
