¿Qué es un ndarray? El Corazón de NumPy

Homogeneidad de Tipo

A diferencia de una lista de Python, donde puedes mezclar peras con manzanas, en un array de NumPy todos los elementos deben ser del mismo tipo.

¿Por qué importa?

Si NumPy sabe que "todo es un entero de 64 bits", reserva un bloque exacto de memoria y calcula en bloque. Como una estantería diseñada para cajas del mismo tamaño: se apilan y mueven mucho más rápido.

Cambio de Forma y Operaciones Elemento a Elemento

reshape: reorganizar sin alterar
  • reshape: cambia la estructura de 1D a 2D sin tocar los datos.
  • Regla: el número total de elementos debe coincidir; 6 elementos no entran en una tabla 2x2.
  • Posición a posición: sumar dos arrays ocurre automáticamente elemento por elemento, sin bucles.
arr = np.arange(1, 7) # [1 2 3 4 5 6] shape (6,) matriz = arr.reshape(2, 3) # [[1 2 3] # [4 5 6]] shape (2, 3) array_A = np.array([1, 2]) array_B = np.array([10, 20]) array_A + array_B # [11, 22] ¡Sin bucles for!

Vectorización frente a Bucles Python

El concepto más importante
  • Enfoque bucle: crear lista vacía, iterar, multiplicar, agregar — 4 pasos.
  • Enfoque NumPy: mi_array * 2 — un solo paso.
  • Claridad: el código se parece a una fórmula matemática real.
  • Velocidad: el procesador multiplica todo el bloque de una vez, no tarea por tarea.
# Bucle: 4 pasos duplicados = [] for x in mi_lista: duplicados.append(x * 2) # Vectorización: 1 paso duplicados_np = mi_array * 2

Broadcasting: el Superpoder de NumPy

Expansión virtual, sin copiar
  • NumPy compara las formas de derecha a izquierda. Son compatibles si son iguales o si una de ellas es 1.
  • "Estira" virtualmente el array más chico, sin copiar datos en memoria.
  • Caso real: restar el promedio de cada grupo a 1,000 alturas sin crear 1,000 copias.
# Matriz 3x2 y vector de medias (2,) matriz_datos = np.array([[20, 100], [30, 200], [40, 300]]) medias = np.array([30, 200]) datos_centrados = matriz_datos - medias # [[-10, -100], # [ 0, 0], # [ 10, 100]]

Multiplicación Elemento a Elemento (*) y Transposición (.T)

Multiplicación (*)

Multiplica posición a posición: (0,0) con (0,0), (0,1) con (0,1), etc. Las dimensiones deben cumplir las reglas de broadcasting. No es álgebra lineal.

Transposición (.T)

Gira la matriz: filas se convierten en columnas. Una 3x2 se vuelve 2x3. No copia datos, solo cambia cómo se leen — extremadamente eficiente. Clave para alinear dimensiones antes de calcular.

Multiplicación Matricial (@) y Casos de Uso Reales

Fila por columna
  • A @ B: el número de columnas de A debe igualar las filas de B.
  • Escalado: ajustar precios por inflación con un escalar (precios * 1.05).
  • Normalización Z-score: (datos - medias) / desviaciones, en una sola línea gracias al broadcasting.
  • Redes neuronales: las predicciones se calculan con multiplicación matricial entre datos y pesos.
A = np.array([[1, 2], [3, 4], [5, 6]]) # 3x2 B = np.array([[10, 20], [30, 40]]) # 2x2 resultado = A @ B # 3x2 @ 2x2 = 3x2 print(resultado)

Producto Punto (Dot Product) y Multiplicación Matricial

De vectores a un escalar
  • Producto punto: multiplica elementos correspondientes y suma los resultados; devuelve un único escalar.
  • Multiplicación matricial: el elemento (i, j) del resultado es el producto punto de la fila i de A y la columna j de B.
  • Estilo moderno: se prefiere el operador @ sobre np.dot() por legibilidad.
v1 = np.array([1, 2, 3]) v2 = np.array([4, 5, 6]) # (1*4)+(2*5)+(3*6) = 4+10+18 = 32 dot_product = np.dot(v1, v2) A = np.array([[1, 2], [3, 4]]) B = np.array([[5, 6], [7, 8]]) C = A @ B # [[19, 22], [43, 50]]

Sistemas de Ecuaciones Lineales: np.linalg.solve

Ax = b, sin calcular la inversa
  • Ax = b: A es la matriz de coeficientes, b los términos independientes, x las incógnitas.
  • Calcular la inversa es ineficiente y propenso a errores de redondeo (inestabilidad numérica).
  • np.linalg.solve: usa descomposición LU, mucho más rápida y estable.
  • Restricción: A debe ser cuadrada y no singular (determinante ≠ 0).
# 3x + 1y = 9 # 1x + 2y = 8 A = np.array([[3, 1], [1, 2]]) b = np.array([9, 8]) x = np.linalg.solve(A, b) # [2., 3.] -> x = 2, y = 3

El Algoritmo de Decisión y la Regla de Oro

Flujo basado en reglas
  • Si una fila tiene más de 1 NA → eliminar el registro completo.
  • Si tiene exactamente 1 NA → imputar con la media de la columna.
  • Regla de oro: las medias deben calcularse ANTES de eliminar filas, usando solo los valores presentes.
# Data Leakage: por qué el orden importa # Si eliminás filas antes de calcular # la media, alterás la distribución # original e invalidás el valor imputado Si (NA en fila i) > 1: eliminar registro Si (NA en fila i) == 1: imputar con media de columna

Outliers y Escalamiento: Winsorización, Z-Score y Robust

Winsorización

En vez de eliminar outliers, se les asigna un tope (percentil 1 y 99), estabilizando la varianza sin perder registros.

Z-Score

Media 0, desviación estándar 1. Altamente sensible a outliers extremos.

Robust Scaling

Usa mediana e IQR (P75 - P25); inmune a la distorsión de valores atípicos. Estándar cuando hay colas largas.

Reproducibilidad

Fijar random seed, versionar cada estado del dataset y loguear metadatos: así el pipeline es auditable.
