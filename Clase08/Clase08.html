¿Qué es el Aprendizaje Supervisado?

El tasador de arte y su aprendiz
  • Le mostrás miles de cuadros etiquetados ("Van Gogh auténtico" / "copia moderna") en vez de darle un manual de reglas mágicas.
  • Con el tiempo, el aprendiz nota patrones sutiles —la pincelada, el pigmento— que vos nunca le explicaste explícitamente.

Features (X) y Target (y)

Features: las variables de entrada (metros², habitaciones, ubicación). Target: lo que querés predecir (precio de venta). El objetivo: encontrar una función f(X) ≈ y.

¿Por Qué se Llama "Supervisado"?

El profesor que corrige
  • El "supervisor" es el científico de datos que ya conoce las etiquetas reales de cada ejemplo.
  • El algoritmo predice, compara su resultado con la etiqueta real (el error), y ajusta sus parámetros internos para reducir ese error en el siguiente intento.

El ciclo de aprendizaje

Predecir → Comparar con la verdad → Ajustar → Repetir miles de veces, hasta que el error sea aceptablemente bajo.

El Pipeline (Flujo de Trabajo) en 4 Pasos

Recolección y Limpieza

Garbage in, garbage out: sin datos etiquetados de calidad, no hay aprendizaje.

División (Train/Test)

Train set (70-80%) para aprender; Test set con datos "nuevos" que el modelo nunca vio.

Entrenamiento (Fit)

El algoritmo analiza el train set buscando patrones que conecten X con y.

Predicción y Evaluación

Comparamos las predicciones del test contra las etiquetas reales que guardamos.

El paso 2 es donde más fallan los principiantes: sin un test set separado, no hay forma honesta de saber si el modelo realmente aprendió.

¿Qué es la Regresión Lineal?

La mejor línea a través de una nube de puntos
  • Simple: una sola variable explicativa (publicidad → ventas).
  • Múltiple: varias variables (publicidad + precio + mes del año).

No pasa por todos los puntos

En datos reales con ruido, ninguna línea recta pasa por todos los puntos a la vez — el objetivo es que quede lo más cerca posible de todos ellos.

El Motor Bajo el Capó: Mínimos Cuadrados

El residuo (error)
  • Cada predicción tiene una diferencia con el valor real: el residuo.
  • Se eleva cada residuo al cuadrado (para que los errores positivos y negativos no se cancelen) y se suma todo.
  • La línea "ganadora" (OLS) es la que logra que esa suma sea la mínima posible.

Por qué importa a un Data Scientist

Como el modelo minimiza el error total, un solo valor extremo (outlier) puede "tironear" de la línea entera y sesgar todos los coeficientes.

Anatomía de la Ecuación: Intercepto y Pendiente

Intercepto (β₀): el punto de partida
  • El valor esperado de y cuando X es igual a cero — ventas si no gastás nada en publicidad.
  • Nota de cautela: a veces no tiene sentido físico (altura de una persona cuando el peso es 0 kg) — ahí es solo un ancla matemática.

Pendiente (β₁): la velocidad de cambio

Cuánto cambia y por cada unidad que aumenta X. Positiva = relación directa; negativa = relación inversa (sube el precio, bajan las ventas).

De la Matemática al Negocio: Interpretación de Coeficientes

Precio = 50.000 + 1.500 × (Metros²)

Por cada m² adicional, el precio de venta sube en promedio $1.500. Ampliar la casa en 10 m² → +$15.000 estimados.

"manteniendo todo lo demás constante"

En regresión múltiple, el coeficiente de "baños" aísla el efecto puro de tener un baño extra, descontando que las casas más grandes suelen tener más baños también.

Árboles de Decisión: la Lógica de las Reglas

Raíz → Nodos → Hojas
  • ¿Ingresos mensuales > $3.000? No → Crédito Denegado (hoja).
  • Sí → ¿Tiene deudas pendientes? No → Aprobado. Sí → Denegado.

Imita el pensamiento humano

Es, posiblemente, el modelo más intuitivo del Machine Learning porque divide el dataset con preguntas "si-entonces", buscando que cada grupo resultante sea lo más "puro" posible.

El Peligro de la Perfección: Overfitting

La regla de la "camisa verde"
  • Un árbol sin límites puede crecer hasta que cada hoja tenga un solo dato — memoriza el training set en vez de generalizar.
  • Regla absurda que podría "aprender": "si el cliente usa camisa verde, denegar crédito".

Cómo controlarlo

max_depth limita qué tanto puede crecer el árbol. min_samples_leaf exige que cada "conclusión" esté respaldada por al menos N ejemplos.

De un Árbol a un Bosque: Random Forest

Un "comité" de árboles, no un experto solo
  • Random Forest entrena cientos de árboles en paralelo sobre el mismo problema.
  • Cuando llega un dato nuevo, todos votan: en clasificación gana la clase mayoritaria; en regresión, se promedia.

Bagging y Bootstrap

Cada árbol entrena con una "bolsa" de datos distinta: filas elegidas al azar con reemplazo del dataset original — algunas se repiten, otras no aparecen.

La Aleatoriedad de Variables: el Toque "Random"

No todos los árboles ven todas las columnas
  • En cada split, un árbol solo puede elegir entre un subconjunto aleatorio de las variables disponibles.
  • Si hubiera una variable muy dominante (ej. "Ingresos"), todos los árboles empezarían siempre por ella.
  • Al forzar a algunos árboles a ignorarla, los obligamos a encontrar otros patrones útiles que el árbol principal podría haber pasado por alto.

Regresión Logística: la Función Sigmoide

A pesar del nombre, es un clasificador
  • La función Sigmoide toma cualquier número y lo "aplasta" para que quede entre 0 y 1.
  • Ese resultado se interpreta como una probabilidad: 0.85 = 85% de probabilidad de ser Clase 1.

El umbral de decisión

Generalmente, si la probabilidad es ≥ 0.5, clasificamos como Clase 1; de lo contrario, Clase 0. Ese umbral se puede ajustar según qué error sea más costoso.

K-Nearest Neighbors (KNN)

"Dime con quién andas y te diré quién eres"
  • Mide la distancia (usualmente euclídea) del dato nuevo contra todos los datos ya conocidos.
  • Selecciona los K vecinos más cercanos y vota: la clase que más se repita es la etiqueta del nuevo dato.

Un algoritmo "perezoso"

KNN no aprende una fórmula matemática — simplemente memoriza los datos y hace todos los cálculos recién en el momento en que le pedís una predicción.

El Rol Crítico del Escalado

Edad (0-100) vs. Ingresos ($0-5.000.000)
  • Como KNN usa distancias, la columna de Ingresos domina completamente el cálculo.
  • Una diferencia de $1.000 en sueldo se ve "gigante" frente a una diferencia de 20 años de edad.

La solución ya la conocés

Siempre hay que escalar los datos (media 0 y desviación 1, o a un rango fijo) antes de usar KNN — el mismo Módulo 02 de la Clase 06.

Generalización: el Verdadero Objetivo

La seta cerca de la piedra gris
  • Si 10 setas venenosas casualmente estaban cerca de una piedra gris, aprender "piedra gris = veneno" es memorizar ruido, no la señal real (forma de las láminas, color).

Ruido vs. Señal

Un modelo con 99% de acierto en el training set no es necesariamente "bueno" — el objetivo nunca es memorizar, es generalizar a datos nuevos.

El Desafío de las Clases Desbalanceadas

99.9% de Accuracy... y un modelo inútil
  • Fraude bancario: 99.9% de las transacciones son legítimas, solo 0.1% son fraude.
  • Un modelo que siempre dice "No es fraude" tiene 99.9% de Accuracy — y falló en detectar el único evento que realmente importaba.

Por eso este checkpoint no se detiene en la Accuracy: usa F1-Score, Curva ROC/AUC y Curva Precision-Recall.

F1-Score y Curva ROC/AUC

F1-Score

La media armónica entre Precision (¿qué tan confiable es cuando dice "positivo"?) y Recall (¿qué % de los positivos reales encontró?). La métrica reina con clases desbalanceadas.

Curva ROC y AUC

Muestra cómo se comporta el modelo al variar el umbral de decisión. AUC = 0.5 es como tirar una moneda al aire; AUC = 1.0 es un modelo perfecto.

CODERHOUSE
43 / 48

Curva Precision-Recall

Más exigente que la ROC
  • Especialmente útil cuando la clase de interés es muy pequeña (enfermedades raras, fallas industriales).

Si tu curva Precision-Recall se ve bien, podés estar seguro de que tu modelo realmente aprendió a identificar la clase minoritaria — no solo la mayoritaria.
