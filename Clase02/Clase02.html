PEP 8: La Guía de Estilo para Python

Fundamentos

Un equipo donde cada quien programa distinto genera código difícil de leer, mantener y compartir.

  • Indentación: 4 espacios por nivel, evitando tabulaciones.
  • Longitud de línea: Máximo 79 caracteres para facilitar la lectura.
  • Nombres: snake_case para variables/funciones, CamelCase para clases.
  • Importaciones: Una por línea, ordenadas y agrupadas.
# Correcto según PEP 8 def calcular_media(valores): suma = sum(valores) cantidad = len(valores) return suma / cantidad

Patrones Idiomáticos en Python

Código Conciso

Construcciones que permiten escribir código más compacto, expresivo y fácil de mantener.

Mutabilidad y el Problema del Aliasing

Copias vs Referencias

Las funciones en Python reciben referencias a objetos, no copias automáticas.

  • Inmutables: int, float, str, tuple — cada operación crea un nuevo objeto en memoria.
  • Mutables: list, dict, set, DataFrame — se modifican en el mismo lugar de memoria.
  • Aliasing: Dos variables distintas apuntan al mismo objeto en memoria.
def modificar(lista): lista.append(100) mi_lista = [1, 2, 3] modificar(mi_lista) print(mi_lista) # Resultado: [1, 2, 3, 100] → Aliasing

¿Qué es NumPy?

Cálculo Numérico

Librería optimizada en C que permite manejar arreglos multidimensionales de forma rápida y eficiente.

  • Optimizada en C: Soluciona la lentitud de Python puro para cálculos numéricos.
  • ndarray: Estructura N-dimensional homogénea, más rápida y liviana que las listas.
  • Vectorización: Ejecuta operaciones sobre arrays completos sin loops explícitos.
  • Base del ecosistema: Pandas, SciPy y Scikit-learn se construyen sobre NumPy.

Atributos de los ndarrays

Inspección

Los arrays exponen atributos que permiten conocer y optimizar su estructura en memoria.

  • ndim: Número de dimensiones del array.
  • shape: Tamaño en cada dimensión.
  • size y dtype: Cantidad total de elementos y su tipo de dato.
  • itemsize y nbytes: Tamaño en bytes de cada elemento y del array total.
import numpy as np # Crear un ndarray de ceros con 10 elementos arr = np.zeros(10) print(arr.ndim) # 1 print(arr.shape) # (10,) print(arr.size) # 10 print(arr.dtype) # float64 print(arr.itemsize) # 8 print(arr.nbytes) # 80

Control de Flujo Avanzado y Generadores

Flujo Avanzado

Más allá de if/else: condicionales complejas y generadores para procesar datos sin saturar la memoria.

  • Condicionales anidadas: if/else combinados y expresiones ternarias.
  • enumerate(): Itera obteniendo índice y valor al mismo tiempo.
  • Generadores (yield): Producen valores bajo demanda sin cargar todo en memoria RAM.
  • itertools: count(), cycle(), chain() e islice() para iterables eficientes.

Funciones de Primera Clase y Closures

Funciones como Objetos

En Python, las funciones pueden asignarse, almacenarse y devolverse como cualquier otro valor.

  • *args: Captura argumentos posicionales adicionales de forma flexible.
  • **kwargs: Captura argumentos con nombre, dando una interfaz común a distintas operaciones.
  • Closures: Funciones que recuerdan y modifican (nonlocal) variables del entorno donde fueron creadas.
def multiplicador(factor): def multiplicar(n): return n * factor return multiplicar doblar = multiplicador(2) print(doblar(5)) # Resultado: 10

Testing Ligero: Debugging y assert

Programación Defensiva

Escribir la función es el 50% del trabajo: el otro 50% es asegurar que se comporte de forma predecible.

  • Errores de Sintaxis, Runtime y Lógica: Estos últimos son los más peligrosos: el código corre pero el resultado es incorrecto.
  • Print debugging: Insertar print() en puntos clave para inspeccionar el estado de las variables.
  • assert: Detiene la ejecución con un AssertionError apenas la condición esperada es falsa.
def mcd(a, b): while b != 0: a, b = b, a % b return a assert mcd(12, 8) == 4 assert mcd(100, 25) == 25 assert mcd(7, 3) == 1

Matplotlib: Figure, Axes y Axis

Jerarquía de Matplotlib

Matplotlib se organiza en tres niveles que permiten un control profesional y detallado.

  • Figure: El lienzo completo donde se dibuja uno o varios gráficos.
  • Axes: Representa cada gráfico individual dentro de la figura.
  • Axis: Corresponde a los ejes X e Y de cada gráfico.
  • fig, ax = plt.subplots(): El estándar profesional para crear subplots y evitar errores visuales.
import matplotlib.pyplot as plt fig, ax = plt.subplots() ax.plot([1, 2, 3], [4, 5, 6]) ax.set_title("Mi gráfico") plt.show()

Medidas de Tendencia Central y Dispersión

Tendencia Central
  • Media: Promedio aritmético, sensible a valores extremos (outliers).
  • Mediana: Valor central, robusta frente a outliers.
  • Moda: Valor más frecuente; clave en variables categóricas.
Dispersión
  • Varianza: Promedio de las diferencias cuadradas respecto a la media.
  • Desviación estándar: Raíz cuadrada de la varianza, en las mismas unidades que los datos.
  • IQR (Q3 − Q1): Rango intercuartílico, muy útil para detectar outliers.

Distribuciones: Normal vs. Uniforme

Distribución Uniforme

Todos los valores dentro de un rango tienen la misma probabilidad de ocurrir. Ejemplo clásico: el lanzamiento de un dado justo, donde cada número tiene 1/6 de probabilidad.

Distribución Normal

Simétrica respecto a su media, con forma de campana de Gauss. La media, mediana y moda coinciden en el centro. Ejemplo: la estatura de una población adulta.
