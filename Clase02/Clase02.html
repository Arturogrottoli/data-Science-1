¿Qué es una Variable y qué es un Dato?

Fundamentos

Antes de operar necesitamos contenedores: una variable es la etiqueta que le pones a un dato en la memoria.

  • El Dato: La unidad de información. Ejemplo: 25, "Juan", True.
  • La Variable: El nombre que usas para referirte a ese dato (edad, nombre_paciente).
  • Tipado dinámico: Python mira el dato y decide el tipo automáticamente, sin declaraciones previas.
# Asignación de datos a variables edad = 30 nombre = "Lucía" # Python detecta el tipo automáticamente print(type(edad)) # <class 'int'> print(type(nombre)) # <class 'str'>

Tipos Escalares: Los Átomos de la Información

int (Enteros)

Números sin decimales. Ej: cantidad_productos = 500 (transacciones, hijos, edad).

float (Flotantes)

Números con decimales, con punto. Ej: precio_dolar = 850.50 (precios, probabilidades).

str (Cadenas)

Secuencias de caracteres entre comillas. Ej: usuario = "data_expert_2024".

bool (Booleanos)

Solo True o False. Ej: es_valido = True (¿tiene nulos?, ¿es premium?).

Cadenas como Secuencia y Escalares vs. Colecciones

El "Collar de Perlas"

Aunque un string parece un dato simple, Python lo trata como una secuencia: puedes contar sus caracteres o pedir uno puntual.

ciudad = "Madrid"
len(ciudad) → 6

Escalar vs. Colección

Escalar no significa "pequeño": significa un solo valor. temperatura = 24.5 es escalar; temperaturas_semana = [24.5, 22.0, 26.1] es una colección que agrupa muchos escalares.

Operadores Aritméticos y de Comparación

El motor matemático
  • Aritméticos: +, -, *, / (decimal), // (entera), % (módulo), ** (potencia).
  • Comparación: ==, !=, >, <, >=, <= — siempre devuelven un booleano.
  • ¡Cuidado! No confundas = (asignar) con == (comparar).
# Aritméticos 7 / 2 # 3.5 (división decimal) 7 // 2 # 3 (división entera) 7 % 2 # 1 (resto/módulo) 2 ** 3 # 8 (potencia) # Comparación 5 == 5 # True 5 != 3 # True

Operadores Lógicos y Conversión de Tipos

Lógica y Casting
  • and: True solo si ambas condiciones son ciertas.
  • or: True si al menos una condición se cumple.
  • not: invierte el valor booleano.
  • Conversión de tipos: "limpia" datos que llegan en el formato incorrecto (ej. un sensor que envía "25.4" como texto).
# Operadores lógicos es_mayor and tiene_saldo pago_tarjeta or pago_efectivo not True # False # Conversión (Casting) int("10") # 10 float("10.5") # 10.5 str(100) # "100" bool(1) # True

Precedencia de Operadores y Errores Comunes

¿Qué va primero?
Orden Operadores
1Paréntesis () — úsalos siempre para mayor claridad
2Potencias **
3Multiplicación, División, Módulo
4Suma y Resta
5Comparaciones (==, >, etc.)
6Operadores lógicos (not, and, or)

Error común: 10 + 5 * 2 es 20, no 30 (el * va antes que el +). Para forzar el orden: (10 + 5) * 2. También cuidado con comparar tipos incompatibles ("5" > 3) y con escribir nombre = Juan sin comillas.

Listas vs. Tuplas: El Dilema de la Mutabilidad

Mutables vs. Inmutables
  • Listas [] (Mutables): crecen, se achican y modifican. Ideales para flujos de datos dinámicos.
  • Tuplas () (Inmutables): una vez creadas no cambian. Protegen la integridad del dato (ej. una fila de base de datos).

Sets: El Arma Secreta para la Limpieza de Datos

Elementos únicos
  • Set {}: colección desordenada de elementos únicos.
  • Deduplicación: elimina registros duplicados en una sola línea de código.
  • Operaciones de conjuntos: cruzar listas de usuarios (intersección, unión).

Decisiones Inteligentes: if, elif y else

Bifurcador de caminos
  • if: evalúa la condición booleana principal.
  • elif: plan alternativo si la primera condición fue falsa; se pueden encadenar varios.
  • else: caso por defecto, captura registros sospechosos.
score_crediticio = 650 if score_crediticio >= 750: estado = "Aprobado Automático" elif score_crediticio >= 600: estado = "Revisión Manual" else: estado = "Rechazado" print(estado) # Revisión Manual

Álgebra Booleana: Lógica Combinada

and (Estricto)

True solo si todas las condiciones son ciertas. Ej: ¿inició sesión Y supera su límite? → Alerta de fraude.

or (Flexible)

True si al menos una condición se cumple. Ej: ¿email vacío O sin arroba? → Registro inválido.

not (Inversión)

Invierte el booleano. Ej: si el registro NO es nulo (not None), procesarlo.

Automatización Masiva: Bucles for y while

El motor de la Ciencia de Datos
  • for: itera sobre colecciones; sabemos cuándo empieza y termina. El "rey" de Data Science.
  • while: se ejecuta mientras una condición sea verdadera; útil para reintentos de API o algoritmos iterativos.

Ajuste Fino de Algoritmos: break y continue

Superpoderes sobre la ejecución
  • break: salida de emergencia, interrumpe el bucle al encontrar el primer error.

Qué es una Función y por qué Reutilizarla

Modularidad

Divide un problema complejo (un pipeline de limpieza) en piezas manejables.

Reutilización

Escribes la lógica una vez y la usas mil veces en distintos proyectos.

Mantenibilidad

Corriges un error en un solo lugar y el cambio se aplica en todo el programa.

Abstracción

Usas la función sabiendo qué necesita y qué entrega, sin pensar en el cómo.

def, Parámetros, Argumentos y return

La anatomía de una función
  • def: define la función; el nombre debe ser descriptivo (usa verbos).
  • Parámetros: moldes que reciben los datos; los argumentos son los valores reales.
  • Posicionales vs. con nombre: el orden importa o no según cómo llames a los argumentos.
  • print() vs return: print() solo muestra en pantalla; return entrega el resultado para reutilizarlo.
def normalizar_categoria(texto): return texto.strip().lower() print(normalizar_categoria(" ELECTRONICA ")) # "electronica" def crear_etiqueta(producto, precio): return f"{producto}: ${precio}" print(crear_etiqueta(precio=40, producto="Pantalón")) # Pantalón: $40

Valores por Defecto, Múltiples Retornos y Scope

Valores por Defecto y Múltiples Retornos

Un parámetro opcional evita repetir siempre el mismo valor (ej. tasa=0.92). Una función puede devolver varios resultados a la vez como tupla (ej. el mínimo y el máximo de una lista de precios).

Ámbito Local (Scope)

Las variables creadas dentro de una función son locales: solo existen mientras se ejecuta y desaparecen al terminar, manteniendo el programa principal ordenado.

Parámetros Avanzados: *args y **kwargs

Flexibilidad total
  • *args: captura cualquier cantidad de argumentos posicionales.
  • **kwargs: captura argumentos con nombre sin declararlos de antemano.

El Peligro del Scope (Global vs. Local)

Efectos secundarios
  • Variable global: vive fuera de las funciones; todo el script la ve.
  • Variable local: nace y muere dentro de la función.
  • Regla de oro: nunca modifiques una variable global dentro de una función de limpieza; pasa el dato como argumento y retorna la copia.
dataset_global = [10, 20, 30] def duplicar_datos(lista_datos): return [x * 2 for x in lista_datos] nuevos_datos = duplicar_datos(dataset_global) print(dataset_global) # [10, 20, 30] intacto print(nuevos_datos) # [20, 40, 60]

Funciones Lambda: Transformaciones Express

De un solo uso
  • Función anónima: se escribe en una sola línea, para tareas de "un solo uso".
  • No reemplaza a def: se usa para transformaciones simples y específicas.
  • Se combina con map() y filter(): la antesala de .apply() en Pandas.
calcular_iva = lambda precio: precio * 1.21 print(calcular_iva(100)) # 121.0 precios = [100, 250, 400] actualizados = list(map(lambda x: x * 1.10, precios)) print(actualizados) # [110.0, 275.0, 440.0]

Datos Faltantes: isnull().sum() y % de Nulos

El detector de agujeros
  • df.isnull().sum(): cuenta los NaN por columna, el paso obligatorio antes de limpiar.
  • El truco pro: df.isnull().mean() * 100 da directamente el porcentaje de nulos.
  • Tabla de diagnóstico: ordena las columnas de mayor a menor % de nulos para priorizar la limpieza.
reporte = df.isnull().mean() * 100 reporte = reporte.sort_values( ascending=False) df_nulos = pd.DataFrame( reporte, columns=['% de Nulos']) display(df_nulos)
